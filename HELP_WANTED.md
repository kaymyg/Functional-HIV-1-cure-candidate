# Help wanted

Functional HIV-1 Cure Candidate is open to contributions. Below is the hardening work that would make it stronger, roughly in order of impact. Pick anything, comment on (or open) an issue so others know you are on it, and see [CONTRIBUTING.md](CONTRIBUTING.md) to get started.

Found a vulnerability instead? Please report it privately, see [SECURITY.md](SECURITY.md).


### Independent expert review

**High impact.** Reviewers with virology, gene therapy or immunology backgrounds: check the design review and model audit and open issues for anything wrong or overstated.

### Reference check

**Good first issue.** Confirm every cited paper exists, is cited accurately and supports the sentence it is attached to.

### Reproducibility of the analysis script

**Medium.** Pin the Python dependencies, add a short README section on how to rerun it, and check the outputs match the document.
